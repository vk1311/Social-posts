You have one 100-sheet cardstock pack, so buy **one more pack** (52 short).

## Every job, every time

- Print at **100% / "Actual size"**, never "Fit to page". Colour on.
- Files marked **2SIDED**: choose **print on both sides, flip on long edge**. Print **1 test sheet** first and hold it to a window. If the printer won't do both sides on cardstock: print the odd pages, put the stack back in the tray turned over side to side (same edge first), then print the even pages.
- Cardstock goes in the side (bypass) tray. Pick "Cardstock" or "Heavy" as the paper type if the printer asks.
